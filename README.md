# AR Face Filters

An Android app that applies real-time, Snapchat-style face filters using Augmented Reality. Point the front camera at your face, pick a filter, and snap a photo to save or share.

Originally themed around **FINKI** graduation, with a graduation-cap filter and a fun "hardest subject" spinner.

## Features

- **Real-time AR face filters** tracked to your face with the front camera.
- **10 filters:**
  - ✕ None
  - 🎓 Graduation - tilted cap with a logo, a "FINKI GRADUATES" banner, and falling confetti
  - 🎲 Hardest - spins through university subjects and lands on a random "hardest" one (tap to spin again)
  - 👓 Glasses
  - 🐶 Dog · 🐱 Cat · 🐰 Bunny
  - 👑 Crown · 😈 Devil · 🤡 Clown
- **Take photos** with a preview screen to **Retake**, **Save**, or **Share**.
- **Save** to your gallery and **share** to Instagram, Facebook, WhatsApp, and other apps.

## Built with

- Kotlin & Jetpack Compose
- Google ARCore (face tracking) via the SceneView library

## Requirements

- An **ARCore-supported Android phone** (face tracking doesn't work on the emulator).
- **Google Play Services for AR** — the app will prompt you to install it if needed.

## Running the app

Open the project in Android Studio, connect your phone, and press **Run ▶**.

## Filters

The 3D filter shapes (ears, crown, horns, etc.) live in `app/src/main/assets/models/`. They're
generated by a small script in the `tools/` folder, so new filters can be added without
hand-modeling. The `tools/` scripts run only on a computer — they're not part of the app.
